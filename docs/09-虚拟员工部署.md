# 🚀 快速执行指南（3步完成部署）

## 准备工作

确保你有：
- ✅ Anthropic API Key（必需）
- ✅ SSH 访问权限（ubuntu@139.199.200.144）
- ✅ 本地已安装 `scp` 或 `rsync` 工具

---

## 第1步：上传部署包到服务器

**在本地 Mac 的 Terminal 中执行：**

```bash
cd ~/.openclaw/workspace/scripts/cloud-deploy

# 上传所有文件到服务器
scp deploy.sh README.md ubuntu@139.199.200.144:/tmp/
```

---

## 第2步：SSH 登录服务器并执行部署

```bash
# 登录服务器
ssh ubuntu@139.199.200.144

# 执行部署脚本
cd /tmp
bash deploy.sh
```

**部署过程中会提示输入：**
- Anthropic API Key（必填）：`sk-ant-api03-...`
- GitHub Copilot Token（选填）：直接回车跳过

**部署大约需要 2-3 分钟**，完成后会显示：
```
=========================================
部署准备完成！
=========================================

下一步：
1. 编辑 .env 文件，填入你的 API Keys
   vim /opt/openclaw/.env

2. 启动服务
   cd /opt/openclaw && bash start.sh

3. 查看状态
   bash status.sh
```

---

## 第3步：启动虚拟员工服务

```bash
# 进入工作目录
cd /opt/openclaw

# （如果部署时没有输入 API Key，现在编辑）
vim .env
# 找到 ANTHROPIC_API_KEY= 这行，填入你的 key

# 启动所有虚拟员工
bash start.sh
```

**首次启动会下载 Docker 镜像（约 500MB），可能需要 3-5 分钟。**

启动成功后会显示：
```
虚拟员工服务已启动！
NAME                STATUS    PORTS
operation-agent     Up        
product-agent       Up        
development-agent   Up        
testing-agent       Up        
openclaw-gateway    Up        0.0.0.0:18789->18789/tcp
```

## ⚠️ 重要提示

### 安全建议

1. **不要将 `.env` 文件提交到 Git**
   ```bash
   echo ".env" >> /opt/openclaw/.gitignore
   ```

2. **定期更新系统和软件**
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

3. **配置防火墙**（仅允许你的 IP 访问）
   ```bash
   sudo ufw allow from YOUR_IP to any port 18789
   sudo ufw enable
   ```

4. **定期备份**
   ```bash
   tar -czf ~/openclaw-backup-$(date +%Y%m%d).tar.gz /opt/openclaw
   ```

### 资源监控

```bash
# 查看容器资源使用
docker stats

# 查看磁盘空间
df -h

# 查看内存使用
free -h
```

## 🐛 遇到问题？

### 容器无法启动
```bash
# 查看详细错误
docker-compose logs operation-agent

# 检查配置
docker-compose config
```

### API Key 错误
```bash
# 编辑 .env
vim /opt/openclaw/.env

# 重启服务
bash stop.sh && bash start.sh
```

### 清理并重新部署
```bash
cd /opt/openclaw
bash stop.sh
docker-compose down -v
rm -rf data/* logs/*
bash start.sh
```

# OpenClaw 企业微信虚拟员工系统

## 📖 项目简介

基于 OpenClaw AI 代理框架，为企业微信构建的多角色虚拟员工系统。支持运营、产品、研发、测试、客服等多种角色，实现智能任务分发和自动化处理。

## 🚀 快速开始

### 1. 查看文档

```bash

cat docs/01-快速开始.md    # 新用户入门
```

### 2. 部署系统

```bash
# 自动打包上传
```
