# 📦 优化脚本部署说明

## 🎯 两种部署方式

### 方式 1：自动上传部署（推荐）

如果你的 SSH 密钥已配置好，可以一键完成打包、上传、部署：

```bash
cd ~/openclaw-deploy
bash deploy-optimizations.sh
```

**这个脚本会自动**：
1. ✅ 检查本地文件
2. ✅ 创建部署包
3. ✅ 测试 SSH 连接
4. ✅ 上传到服务器
5. ✅ 在服务器上解压并部署

### 方式 2：手动打包上传

如果 SSH 连接有问题，或想手动控制：

```bash
cd ~/openclaw-deploy

# 1. 仅打包（不上传）
bash package-only.sh

# 2. 手动上传到服务器
scp openclaw-optimization-*.tar.gz ubuntu@139.199.200.144:~/

# 3. 登录服务器
ssh ubuntu@139.199.200.144

# 4. 在服务器上部署
tar -xzf openclaw-optimization-*.tar.gz
cd openclaw-optimization-*/
sudo bash quick-deploy.sh
```

## 🚀 服务器上的部署步骤

### 快速版（使用 quick-deploy.sh）

```bash
# 解压部署包
tar -xzf openclaw-optimization-*.tar.gz
cd openclaw-optimization-*/

# 一键部署
sudo bash quick-deploy.sh

# 执行优化脚本
cd /opt/openclaw
sudo bash scripts/setup_secrets.sh
sudo bash scripts/setup_network_isolation.sh
sudo bash scripts/setup_alerting.sh
```

### 详细版（逐步执行）

```bash
# 1. 解压
tar -xzf openclaw-optimization-*.tar.gz
cd openclaw-optimization-*/

# 2. 查看说明
cat README.md

# 3. 移动脚本到目标位置
sudo mkdir -p /opt/openclaw/scripts
sudo mkdir -p /opt/openclaw/docs

sudo cp scripts/*.sh /opt/openclaw/scripts/
sudo chmod +x /opt/openclaw/scripts/*.sh

sudo cp docs/*.md /opt/openclaw/docs/

# 4. 执行优化（按顺序）
cd /opt/openclaw

# API Key 安全配置（交互式输入凭证）
sudo bash scripts/setup_secrets.sh

# 网络隔离配置
sudo bash scripts/setup_network_isolation.sh

# 监控告警配置（交互式输入企业微信/邮件配置）
sudo bash scripts/setup_alerting.sh
```

## ⚙️ 脚本详细说明

### 1. setup_secrets.sh - API Key 安全配置

**功能**：
- 创建 `/opt/openclaw/secrets/` 目录
- 交互式输入敏感凭证
- 设置文件权限为 400（仅 root 可读）
- 生成安全版 docker-compose-secrets.yml

**需要输入的凭证**：
- Anthropic API Key
- 企业微信 Corp Secret
- 企业微信 Encoding AES Key
- 企业微信 Token
- Grafana 管理员密码

**执行后**：
```bash
# 验证 secrets 文件
ls -l /opt/openclaw/secrets/

# 使用新的 docker-compose 文件
cd /opt/openclaw
docker-compose -f docker-compose-secrets.yml up -d
```

### 2. setup_network_isolation.sh - 网络隔离配置

**功能**：
- 创建 3 个隔离 Docker 网络
- 配置持久化 iptables 规则
- 创建 systemd 服务（开机自动加载）
- 生成网络隔离版 docker-compose-network.yml
- 添加容器安全配置

**网络架构**：
- `openclaw-network` (172.20.0.0/16): 主网络
- `openclaw-agents-internal` (172.21.0.0/16): Agent 内部通信
- `openclaw-monitor` (172.22.0.0/16): 监控专用

**执行后**：
```bash
# 验证网络创建
docker network ls | grep openclaw

# 验证网络隔离
bash /opt/openclaw/scripts/verify_network_isolation.sh

# 查看防火墙规则
sudo iptables -L DOCKER-USER -n -v

# 使用新的 docker-compose 文件
docker-compose -f docker-compose-network.yml up -d
```

### 3. setup_alerting.sh - 监控告警配置

**功能**：
- 配置 Prometheus Alertmanager
- 支持企业微信、邮件告警
- 创建 15+ 告警规则
- 3 级严重度分级（P0/P1/P2）
- 生成 docker-compose-alertmanager.yml

**需要输入的配置**：
- 企业微信机器人 Webhook URL（可选）
- 企业微信提醒人 ID
- SMTP 服务器配置（可选）

**执行后**：
```bash
# 启动 Alertmanager
docker-compose -f /opt/openclaw/config/docker-compose-alertmanager.yml up -d

# 重启 Prometheus 加载告警规则
docker restart prometheus

# 访问 Alertmanager Web UI
# http://your-server:9093

# 测试告警
curl -X POST http://localhost:9093/api/v1/alerts \
  -d '[{"labels":{"alertname":"Test","severity":"warning"},"annotations":{"summary":"测试告警"}}]'
```

## 🔧 常见问题

### 问题 1：脚本执行权限不足

**症状**：`Permission denied`

**解决**：
```bash
sudo bash scripts/setup_*.sh
# 或者
chmod +x scripts/*.sh
sudo ./scripts/setup_*.sh
```

### 问题 2：Docker 网络冲突

**症状**：`network already exists`

**解决**：
```bash
# 先删除现有网络
docker network rm openclaw-network openclaw-agents-internal openclaw-monitor

# 重新运行脚本
sudo bash scripts/setup_network_isolation.sh
```

### 问题 3：端口被占用

**症状**：`port is already allocated`

**解决**：
```bash
# 查看端口占用
sudo netstat -tlnp | grep -E '9090|9093|8000'

# 停止冲突的服务
docker stop <container_name>
```
