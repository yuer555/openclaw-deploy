# 生产部署指南

> 多 Agent 独立配置架构 - 生产部署方案（Docker 固定 IP）

## 架构概览

```
生产服务器
├── Gateway (宿主机, :8000) - Flask 应用
│   ├── /operation/wecom/callback    → 172.20.0.11:18789
│   ├── /product/wecom/callback      → 172.20.0.12:18789
│   ├── /development/wecom/callback  → 172.20.0.13:18789
│   ├── /testing/wecom/callback      → 172.20.0.14:18789
│   └── /service/wecom/callback      → 172.20.0.15:18789
│
├── openclaw-agent-operation   172.20.0.11:18789  (expose only)
├── openclaw-agent-product     172.20.0.12:18789  (expose only)
├── openclaw-agent-development 172.20.0.13:18789  (expose only)
├── openclaw-agent-testing     172.20.0.14:18789  (expose only)
└── openclaw-agent-service     172.20.0.15:18789  (expose only)

Docker 子网: 172.20.0.0/16 (openclaw-prod-net)
```

**架构说明**：
- Gateway 在宿主机运行，监听 8000 端口，通过 URL 路径路由到不同 Agent
- Agent 容器不暴露宿主机端口，仅通过 Docker 固定 IP 互访
- 每个 Agent 可通过 `.env.prod` 独立启用/禁用
- 支持 Docker Compose profiles 机制

---

## 前置条件

- Ubuntu 22.04 LTS（推荐）或其他 Linux 发行版
- Docker + Docker Compose
- 至少 8 核 CPU，16GB 内存，50GB 磁盘
- 公网 IP（企业微信回调需要）
- Python 3.13+（宿主机运行 Gateway）
- Node.js 25+（宿主机安装 openclaw）
- GitHub Token 或 OpenAI API Key

## 部署流程

### 第一步：准备服务器环境（全新服务器）

```bash
cd production/
./setup-host-gateway.sh
```

**功能**：从零安装所有依赖
1. 安装 Docker + Docker Compose
2. 安装 Python 3.13
3. 安装 Node.js 25
4. 安装 openclaw CLI（全局）
5. 安装 Python 依赖（flask, requests, pycryptodome, websocket-client）
6. 创建数据目录
7. 配置环境

**执行时间**：约 5-10 分钟（取决于网络速度）

> **注意**：如果服务器已有 Docker/Python/Node.js，可跳过此步骤

---

### 第二步：上传代码

**方式 1：从 Git 拉取（推荐）**

```bash
# 在服务器上
cd /opt/openclaw
git clone https://github.com/your-repo/openclaw-deploy.git
cd openclaw-deploy
git checkout 20260302_feat_remove_dispatcher
```

**方式 2：本地上传**

```bash
# 在本地执行
cd production/
./2-upload-to-server.sh

# 或手动 scp/rsync
rsync -avz --exclude='node_modules' --exclude='data' \
  ../. root@your-server:/opt/openclaw/openclaw-deploy/
```

---

### 第三步：构建镜像

```bash
# 在服务器 production/ 目录执行
cd /opt/openclaw/openclaw-deploy/production/
./3-deploy-production.sh
```

**功能**：
- 创建 `/opt/openclaw/data/` 目录结构
- 构建 `openclaw-base:prod` 基础镜像
- 构建 5 个 `openclaw-agent-{role}:prod` 镜像（operation、product、development、testing、service）

**执行时间**：约 10-15 分钟（首次构建）

---

### 第四步：配置环境变量

```bash
# 复制示例文件
cp .env.prod.example .env.prod

# 编辑配置
vi .env.prod
```

**必填项**：

```bash
# === AI 模型配置（必填）===
API_KEY=your_api_key_here
API_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4
MODEL_PROVIDER=openai
MODEL_API=openai-responses

# === OpenClaw 配置 ===
OPENCLAW_INTERNAL_TOKEN=openclaw-internal-secret-change-me

# === Agent 启用配置（至少启用一个）===
# 运营专员
AGENT_OPERATION_ENABLE=true
AGENT_OPERATION_WECOM_TOKEN=your_operation_token_here
AGENT_OPERATION_WECOM_ENCODING_AES_KEY=your_operation_key_here
AGENT_OPERATION_PORT=18791
AGENT_OPERATION_URL=http://172.20.0.11:18789

# 产品经理
AGENT_PRODUCT_ENABLE=false
# AGENT_PRODUCT_WECOM_TOKEN=...
# AGENT_PRODUCT_WECOM_ENCODING_AES_KEY=...
# AGENT_PRODUCT_PORT=18792
# AGENT_PRODUCT_URL=http://172.20.0.12:18789

# 开发工程师
AGENT_DEVELOPMENT_ENABLE=true
AGENT_DEVELOPMENT_WECOM_TOKEN=your_development_token_here
AGENT_DEVELOPMENT_WECOM_ENCODING_AES_KEY=your_development_key_here
AGENT_DEVELOPMENT_PORT=18793
AGENT_DEVELOPMENT_URL=http://172.20.0.13:18789

# 测试工程师、客服专员类似...
```

**注意事项**：
- 每个 Agent 需要独立的企业微信 Token/Key（对应不同的企业微信应用）
- `AGENT_{ROLE}_URL` 使用 Docker 固定 IP（与 docker-compose.prod.yml 一致）
- 只有 `AGENT_{ROLE}_ENABLE=true` 的 Agent 会被启动

---

### 第五步：启动服务

```bash
./5-start-production.sh
```

**功能**：
- 根据 `.env.prod` 中的 `AGENT_{ROLE}_ENABLE` 配置，启动对应的 Agent 容器
- 在宿主机启动 Gateway (Flask)
- 使用 Docker Compose profiles 机制

**验证启动**：

```bash
# 查看容器状态
docker ps --filter "name=openclaw-"

# 查看 Gateway 进程
ps aux | grep wecom_gateway

# 查看 Gateway 日志
tail -f /tmp/openclaw/flask.log
```

---

### 第六步：健康检查

```bash
./6-health-check.sh
```

**检查项**：
- Gateway 健康检查（`http://localhost:8000/health`）
- 所有 enabled Agents 健康检查
- Docker 容器状态
- 网络连通性

**预期输出**：

```
✅ Gateway 健康检查通过
✅ Agent operation 健康检查通过
✅ Agent development 健康检查通过
⚠️  Agent product 未启用
```

## 企业微信配置

### 配置回调 URL

每个 Agent 对应一个企业微信应用，需要分别配置回调 URL：

| Agent | 企业微信应用 | 回调 URL |
|-------|-------------|---------|
| 运营专员 | 运营助手 | `http://your-server:8000/operation/wecom/callback` |
| 产品经理 | 产品助手 | `http://your-server:8000/product/wecom/callback` |
| 开发工程师 | 开发助手 | `http://your-server:8000/development/wecom/callback` |
| 测试工程师 | 测试助手 | `http://your-server:8000/testing/wecom/callback` |
| 客服专员 | 客服助手 | `http://your-server:8000/service/wecom/callback` |

### 配置步骤

1. 登录企业微信管理后台
2. 进入「应用管理」→ 选择对应应用（如「运营助手」）
3. 进入「接收消息」配置
4. 填写：
   - **URL**: `http://your-server:8000/operation/wecom/callback`
   - **Token**: 与 `.env.prod` 中的 `AGENT_OPERATION_WECOM_TOKEN` 一致
   - **EncodingAESKey**: 与 `AGENT_OPERATION_WECOM_ENCODING_AES_KEY` 一致
5. 点击「验证」，等待验证成功
6. 保存配置

### HTTPS 支持

企业微信要求回调 URL 使用 HTTPS。有两种方案：

**方案 1：使用 Nginx 做 SSL 终止（推荐）**

```bash
# 安装 Nginx + Certbot
./4-setup-ssl.sh

# Nginx 配置示例
server {
    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

回调 URL 改为：`https://your-domain.com/operation/wecom/callback`

**方案 2：使用云服务商的负载均衡器**

在阿里云/腾讯云配置 HTTPS 监听器，转发到 8000 端口。

## 常用运维命令

```bash
# 查看所有容器状态
docker ps --filter "name=openclaw-"

# 查看 Gateway 日志
tail -f /tmp/openclaw/flask.log

# 查看某个 Agent 日志
docker logs openclaw-agent-development -f --tail=100

# 重启 Gateway（不重启容器）
pkill -f wecom_gateway.py

# 重启单个 Agent 容器
docker restart openclaw-agent-operation

# 停止所有服务
./production/stop-production.sh  # 或
docker compose -f docker-compose.prod.yml --env-file .env.prod down
pkill -f wecom_gateway.py

# 清理所有容器和镜像（危险操作！）
./7-clean-production.sh

# 更新代码后重新部署
git pull
./3-deploy-production.sh  # 重新构建镜像
./5-start-production.sh   # 重启服务
```

## 故障排查

### 容器启动失败

```bash
# 查看容器日志
docker logs openclaw-agent-operation --tail=100

# 检查镜像是否构建成功
docker images | grep openclaw

# 重新构建镜像
cd production/
./3-deploy-production.sh
```

### Gateway 启动失败

```bash
# 查看日志
tail -f /tmp/openclaw/flask.log

# 检查 Python 依赖
cd src/gateway/
pip3 list | grep -E "flask|requests|pycryptodome|websocket"

# 重新安装依赖
pip3 install -r requirements.txt

# 检查环境变量
source production/.env.prod
env | grep AGENT
```

### Agent 无法访问

确认 Docker 网络和固定 IP 配置正确：

```bash
# 检查 Docker 网络
docker network inspect openclaw-prod-net

# 检查容器 IP
docker inspect openclaw-agent-operation | grep IPAddress

# 从 Gateway 宿主机测试连接
curl http://172.20.0.11:18789/health
```

### 企业微信回调验证失败

```bash
# 检查 Token/Key 配置
cat production/.env.prod | grep AGENT_OPERATION_WECOM

# 查看 Gateway 日志中的解密错误
tail -f /tmp/openclaw/flask.log | grep -i "decrypt\|signature"

# 手动测试回调
curl "http://localhost:8000/operation/wecom/callback?msg_signature=xxx&timestamp=xxx&nonce=xxx&echostr=xxx"
```

### AI 响应超时

```bash
# 检查 AI 模型配置
cat production/.env.prod | grep -E "API_KEY|MODEL"

# 检查 Agent 日志
docker logs openclaw-agent-development | grep -i "error\|timeout"

# 调整超时时间
vi production/.env.prod
# OPENCLAW_TIMEOUT=3600  # 增加到 1 小时
```

## 安全加固

### 1. 修改默认 Token

```bash
# 生成随机 Token
openssl rand -hex 32

# 更新 .env.prod
OPENCLAW_INTERNAL_TOKEN=<新生成的 Token>
```

### 2. 限制 Gateway 端口访问

```bash
# 使用 iptables 限制只允许企业微信 IP 访问
iptables -A INPUT -p tcp --dport 8000 -s <企业微信 IP 段> -j ACCEPT
iptables -A INPUT -p tcp --dport 8000 -j DROP
```

### 3. 定期更新依赖

```bash
# 更新 Python 依赖
cd src/gateway/
pip3 install --upgrade -r requirements.txt

# 更新 Docker 镜像
docker pull node:25-alpine
./3-deploy-production.sh
```
