# 生产部署指南

> 三层 Docker 架构生产部署方案（Docker 固定 IP，无 Nginx）

## 架构概览

```
生产服务器
├── openclaw-gateway  172.20.0.10:8000  (ports: 8000)
│   ├── Flask 网关（企业微信 + Telegram）
│   └── openclaw 调度员（:18789，内部）
├── openclaw-agent-operation   172.20.0.11:18789  (expose only)
├── openclaw-agent-product     172.20.0.12:18789  (expose only)
├── openclaw-agent-development 172.20.0.13:18789  (expose only)
├── openclaw-agent-testing     172.20.0.14:18789  (expose only)
└── openclaw-agent-service     172.20.0.15:18789  (expose only)

Docker 子网: 172.20.0.0/16 (openclaw-prod-net)
```

Agent 容器不暴露宿主机端口，仅通过 Docker 固定 IP 互访。

---

## 前置条件

- Ubuntu 22.04 LTS（推荐）或其他 Linux 发行版
- Docker + Docker Compose
- 至少 8 核 CPU，16GB 内存，50GB 磁盘
- 公网 IP（企业微信回调需要）
- GitHub Token 或 OpenAI API Key

## 部署流程

### 第一步：准备服务器

```bash
cd production/
./1-prepare-server.sh
```

安装 Docker、Docker Compose 等依赖。

### 第二步：上传代码

```bash
# 在本地执行
./2-upload-to-server.sh
```

或手动将项目目录上传到服务器。

### 第三步：部署（构建镜像 + 创建目录）

```bash
# 在服务器 production/ 目录执行
./3-deploy-production.sh
```

- 创建 `/opt/openclaw/data/` 目录结构
- 构建 `openclaw-gateway:prod` 镜像
- 构建 5 个 `openclaw-agent-{role}:prod` 镜像

### 第四步：配置环境变量

```bash
vi .env.prod
```

必填项：

```bash
GITHUB_TOKEN=your_github_token

# 企业微信
WECOM_CORP_ID=your_corp_id
WECOM_SECRET=your_secret
WECOM_TOKEN=your_token
WECOM_ENCODING_AES_KEY=your_key
WECOM_AGENT_ID=your_agent_id

# Docker 固定 IP（与 docker-compose.prod.yml 一致）
AGENT_OPERATION_URL=http://172.20.0.11:18789
AGENT_PRODUCT_URL=http://172.20.0.12:18789
AGENT_DEVELOPMENT_URL=http://172.20.0.13:18789
AGENT_TESTING_URL=http://172.20.0.14:18789
AGENT_SERVICE_URL=http://172.20.0.15:18789
```

### 第五步：启动服务

```bash
./5-start-production.sh
```

启动所有容器，等待 Gateway 健康检查通过。

### 第六步：健康检查

```bash
./6-health-check.sh
```

检查所有容器状态和 HTTP 健康检查。

## 企业微信配置

Gateway 监听 `http://<服务器IP>:8000/wecom/callback`。

在企业微信管理后台配置：
- 回调 URL：`http://<服务器IP>:8000/wecom/callback`
- Token：与 `WECOM_TOKEN` 一致
- EncodingAESKey：与 `WECOM_ENCODING_AES_KEY` 一致

> 注意：企业微信要求回调 URL 使用 HTTPS。如需 HTTPS，在 Gateway 前加 Nginx 或云负载均衡器做 SSL 终止。

## Telegram 配置

```bash
# Webhook 模式
TELEGRAM_MODE=webhook
TELEGRAM_BOT_TOKEN=your_token
TELEGRAM_WEBHOOK_SECRET=your_secret
# 在 BotFather 设置 Webhook URL: http://<IP>:8000/telegram/webhook

# 或长轮询模式（无需公网 HTTPS）
TELEGRAM_MODE=polling
TELEGRAM_BOT_TOKEN=your_token
```

## 常用运维命令

```bash
# 查看所有容器状态
docker compose -f docker-compose.prod.yml ps

# 查看 gateway 日志
docker logs openclaw-gateway -f

# 查看某个 agent 日志
docker logs openclaw-agent-testing -f

# 重启单个容器
docker restart openclaw-agent-operation

# 停止所有服务
docker compose -f docker-compose.prod.yml --env-file .env.prod down

# 更新镜像后重启
./3-deploy-production.sh && ./5-start-production.sh
```

## 故障排查

**容器启动失败**

```bash
docker logs openclaw-gateway --tail=100
docker logs openclaw-agent-operation --tail=100
```

**Agent 无法访问**

确认 Docker 网络和固定 IP 配置正确：

```bash
docker network inspect openclaw-prod-net
docker inspect openclaw-agent-operation | grep IPAddress
```

**AI 路由不工作**

检查调度员 openclaw 是否正常运行：

```bash
curl http://localhost:8000/health
# 在 gateway 容器内检查调度员
docker exec openclaw-gateway curl http://localhost:18789/health
```
