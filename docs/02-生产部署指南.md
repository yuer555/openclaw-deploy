# 🚀 生产部署指南

> 完整的生产环境部署流程 - 从服务器准备到上线运行

## 📖 适用场景

本指南适用于：
- ✅ 将 OpenClaw 部署到云服务器
- ✅ 供团队正式使用
- ✅ 对接企业微信
- ✅ 配置 SSL 证书和域名

## ⚠️ 前置要求

### 硬件要求
| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 8 核 | 16 核 |
| 内存 | 16GB | 32GB |
| 磁盘 | 50GB SSD | 100GB SSD |
| 带宽 | 5Mbps | 10Mbps+ |

### 软件要求
- ✅ Ubuntu 22.04 LTS（推荐）
- ✅ Root 或 sudo 权限
- ✅ 公网 IP 地址

### 域名和证书
- ✅ 已备案的域名（中国大陆服务器必须）
- ✅ 域名已解析到服务器 IP
- ✅ 准备申请 SSL 证书

### 企业微信
- ✅ 企业微信管理员权限
- ✅ 企业 ID、应用 ID 等信息
- ✅ 参考 [企业微信配置文档](04-企业微信配置.md)

### API Key
- ✅ GitHub Copilot Token 或 OpenAI API Key
- ✅ 参考 [GitHub Copilot 配置](10-GitHub-Copilot配置.md)

## 步骤 1：准备服务器环境

### 1.1 登录服务器

```bash
# 从本地电脑 SSH 登录到服务器
ssh root@your_server_ip

# 或使用指定用户
ssh ubuntu@your_server_ip
```

### 1.2 运行准备脚本

**方法A：在服务器上直接运行**（推荐）

```bash
# 下载准备脚本
wget https://your-domain.com/1-prepare-server.sh

# 或使用 curl
curl -O https://your-domain.com/1-prepare-server.sh

# 赋予执行权限
chmod +x 1-prepare-server.sh

# 运行脚本
./1-prepare-server.sh
```

**方法B：从本地上传后运行**

```bash
# 在本地
cd /Users/marty/openclaw-deploy/production
scp 1-prepare-server.sh ubuntu@your_server_ip:~/

# 在服务器上
chmod +x 1-prepare-server.sh
./1-prepare-server.sh
```

### 1.3 脚本执行内容

准备脚本会自动完成：
- ✅ 更新系统软件包
- ✅ 安装 Docker 和 Docker Compose
- ✅ 配置防火墙（UFW）
- ✅ 创建应用目录 `/opt/openclaw`
- ✅ 优化系统参数

**预计时间**：5-10 分钟

---

## 步骤 2：上传项目文件

### 2.1 在本地运行上传脚本

```bash
# 在本地电脑
cd /Users/marty/openclaw-deploy/production

# 运行上传脚本
./2-upload-to-server.sh
```

### 2.2 配置服务器信息

脚本会询问：
```
服务器 IP 地址 [139.199.200.144]: your_server_ip
服务器用户名 [ubuntu]: ubuntu
远程部署目录 [/opt/openclaw]: /opt/openclaw
```

### 2.3 SSH 密钥配置

如果提示 SSH 连接失败，需要先配置密钥：

```bash
# 在本地生成 SSH 密钥（如未生成）
ssh-keygen -t rsa -b 4096

# 复制公钥到服务器
ssh-copy-id ubuntu@your_server_ip

# 或手动复制
cat ~/.ssh/id_rsa.pub | ssh ubuntu@your_server_ip "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

### 2.4 验证上传

上传成功后，登录服务器检查：

```bash
ssh ubuntu@your_server_ip
cd /opt/openclaw
ls -la
```

应该看到：
```
drwxr-xr-x  production/
drwxr-xr-x  config/
drwxr-xr-x  docs/
-rw-r--r--  README.md
```

**预计时间**：2-5 分钟（取决于网络速度）

## 步骤 3：部署生产服务

### 3.1 进入部署目录

```bash
# 在服务器上
cd /opt/openclaw/production
```

### 3.2 运行部署脚本

```bash
./3-deploy-production.sh
```

### 3.3 配置环境变量

脚本会自动创建 `.env.prod` 文件，需要编辑填写：

```bash
vi .env.prod
```

**必须修改的配置：**

```bash
# 域名
DOMAIN=openclaw.yourdomain.com

# GitHub Token（二选一）
GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 或 OpenAI API Key
# OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 安全密钥（必须修改！）
SECRET_KEY=$(openssl rand -hex 32)

# 企业微信配置
WECOM_CORP_ID=your_corp_id
WECOM_AGENT_ID=your_agent_id
WECOM_SECRET=your_secret
WECOM_TOKEN=your_token
WECOM_ENCODING_AES_KEY=your_aes_key
```

**保存并退出**：按 `ESC`，输入 `:wq`，回车

### 3.4 验证配置

```bash
# 检查配置文件
cat .env.prod | grep -E "GITHUB_TOKEN|WECOM_CORP_ID|DOMAIN"

# 验证 Docker Compose 配置
docker compose -f docker-compose.prod.yml config
```

**预计时间**：5-10 分钟

## 步骤 4：配置 SSL 证书

### 4.1 确认域名解析

```bash
# 检查域名解析
dig +short openclaw.yourdomain.com

# 或
nslookup openclaw.yourdomain.com

# 应该返回你的服务器 IP
```

### 4.2 运行 SSL 配置脚本

```bash
./4-setup-ssl.sh
```

### 4.3 输入域名和邮箱

```
输入你的域名（例如: openclaw.yourdomain.com）: openclaw.yourdomain.com
输入你的邮箱（用于证书通知）: admin@yourdomain.com
```

### 4.4 证书申请

脚本会自动：
- ✅ 安装 Certbot
- ✅ 验证域名解析
- ✅ 申请 Let's Encrypt 证书
- ✅ 配置自动更新
- ✅ 复制证书到项目目录

**证书位置：**
- 系统：`/etc/letsencrypt/live/your_domain/`
- 项目：`/opt/openclaw/config/ssl/`

**预计时间**：3-5 分钟

### 4.5 跳过 SSL（可选）

如果暂时不配置 SSL（测试环境），可以跳过此步骤，直接启动服务。

⚠️ **注意**：生产环境强烈建议配置 SSL！

## ❓ 常见问题

### Q1: 容器启动后立即退出？

**检查：**
```bash
docker logs openclaw-production --tail=100
```

**常见原因：**
- API Key 配置错误
- 环境变量格式错误
- 端口被占用

**解决：**
```bash
# 检查配置
vi .env.prod

# 重启服务
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d
```

### Q2: SSL 证书申请失败？

**检查：**
- 域名是否正确解析到服务器
- 端口 80 是否被防火墙阻止
- 是否有其他服务占用 80 端口

**解决：**
```bash
# 检查域名解析
dig +short your_domain

# 检查端口
sudo netstat -tuln | grep :80

# 停止占用端口的服务
sudo systemctl stop nginx apache2
```

### Q3: 企业微信回调失败？

**检查：**
- 回调 URL 是否配置正确
- SSL 证书是否有效
- 服务器是否可以访问

**调试：**
```bash
# 查看企业微信相关日志
docker logs openclaw-production -f | grep wecom

# 测试回调接口
curl https://your_domain/api/wecom/callback
```

### Q4: 服务运行缓慢？

**检查资源使用：**
```bash
# 系统资源
top
free -h
df -h

# 容器资源
docker stats openclaw-production
```

**优化：**
- 增加服务器配置
- 调整 Docker 资源限制
- 优化数据库查询
