## 🚀 实施计划

### 第一阶段：备份与准备

```bash
# 1. 创建备份
cd ~/openclaw-deploy
tar -czf openclaw-deploy-backup-$(date +%Y%m%d).tar.gz .

# 2. 创建新的分支（如果使用 git）
git checkout -b structure-refactor
```

### 第二阶段：创建新结构

```bash
# 创建新目录结构
mkdir -p docs/{archives}
mkdir -p scripts/{setup,deploy,user,ops,security,test,utils}
mkdir -p src/gateway
mkdir -p config/{agents,nginx,prometheus,alertmanager}
```

### 第三阶段：移动文件

```bash
# 移动脚本
mv scripts/setup_*.sh scripts/setup/
mv deploy-optimizations.sh package-only.sh scripts/deploy/

# 复制核心脚本（从 openclaw-wecom-project）
cp openclaw-wecom-project/scripts/init_*.sh scripts/setup/
cp openclaw-wecom-project/scripts/deploy.sh scripts/deploy/
cp openclaw-wecom-project/scripts/add_user.sh scripts/user/
# ... 其他脚本

# 移动配置
mv config/agents/*.yaml config/agents/

# 移动源码
cp openclaw-wecom-project/src/gateway/wecom_gateway.py src/gateway/
```

### 第四阶段：清理

```bash
# 删除冗余目录
rm -rf openclaw-wecom-project/
rm -rf deploy-package/
rm -rf mission-control/
rm -rf wecom_gateway/
rm -rf workspace/
rm -rf venv/

# 删除过时文档
rm -f DEPLOYMENT_STATUS.md
rm -f 一键复制命令.txt
# ... 其他过时文件

# 删除压缩包
rm -f *.tar.gz
```
