## 🎯 两种部署模式

### 模式A：企业微信网关（原有功能）

**用途**：作为企业微信的消息网关，接收和处理企业微信消息

**配置文件**：`config/docker-compose.yml`

**组件**：
- Nginx 反向代理
- 企业微信网关服务
- 数据库
- 监控系统

**部署方式**：
```bash
bash scripts/deploy/deploy-optimizations.sh
```

**文档**：`docs/04-企业微信配置.md`

---

### 模式B：虚拟员工容器（新增功能）🆕

**用途**：独立运行的虚拟员工容器，可通过 OpenClaw Gateway 或其他方式接入

**配置文件**：`config/docker-compose.agents.yml`

**组件**：
- 运营虚拟员工（operation-agent）
- 产品虚拟员工（product-agent）
- 研发虚拟员工（development-agent）
- 测试虚拟员工（testing-agent）

**特性**：
- 使用 node:24-alpine 基础镜像
- 容器内动态安装 OpenClaw
- 支持 GitHub Copilot 模型
- 自动安装 git（修复依赖问题）

**部署方式**：
```bash
bash scripts/deploy/local-deploy-agents.sh
```

**文档**：`docs/09-虚拟员工部署.md`

## 🔧 关键修复

### 问题：Alpine 镜像缺少 git

**现象**：
```
npm error syscall spawn git
npm error errno -2
npm error enoent An unknown git error occurred
```

**原因**：
- node:24-alpine 不包含 git
- OpenClaw 某些依赖（如 libsignal-node）需要通过 git 克隆安装

**解决方案**：
在容器启动命令中添加：
```yaml
command: sh -c "apk add --no-cache git && npm install -g openclaw@latest && openclaw gateway start"
```

**影响文件**：
- `config/docker-compose.agents.yml`
- `scripts/deploy/deploy-agents.sh`
