## 一、日常运维

### 1.1 服务状态检查

**每日检查清单：**

```bash
#!/bin/bash
# daily_check.sh

echo "=========================================="
echo "  OpenClaw 企业微信 - 每日健康检查"

echo "=========================================="

# 1. Docker 容器状态
echo "1. Docker 容器状态:"
docker compose ps
echo ""

# 2. 健康检查

curl -s http://localhost:8080/stats | jq .

echo "4. 磁盘空间:"
df -h | grep -E '(Filesystem|/$|/data)'

free -h

docker compose logs --tail=100 | grep -i error | tail -10

echo "=========================================="
```

```bash

```

## 二、监控告警

### 2.1 监控指标

#### 系统指标

| 指标 | 阈值 | 告警 |
|-----|------|------|
| CPU 使用率 | > 80% | 警告 |
| 内存使用率 | > 85% | 警告 |
| 磁盘使用率 | > 80% | 警告 |
| 磁盘 I/O 等待 | > 50% | 警告 |

#### 应用指标

| 指标 | 阈值 | 告警 |
|-----|------|------|
| 响应时间（P95） | > 3秒 | 警告 |
| 错误率 | > 5% | 严重 |
| 容器重启次数 | > 5/小时 | 严重 |
| 数据库连接失败 | > 0 | 严重 |

---

### 2.2 监控脚本

**CPU 监控：**
```bash
#!/bin/bash
# monitor_cpu.sh

THRESHOLD=80
CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | sed "s/.*, *\([0-9.]*\)%* id.*/\1/" | awk '{print 100 - $1}')

if (( $(echo "$CPU_USAGE > $THRESHOLD" | bc -l) )); then
    echo "⚠️  警告：CPU 使用率 ${CPU_USAGE}% 超过阈值 ${THRESHOLD}%"
    # 发送告警（可选）
    # ./scripts/send_alert.sh "CPU 使用率过高: ${CPU_USAGE}%"
fi
```

**内存监控：**
```bash
#!/bin/bash
# monitor_memory.sh

THRESHOLD=85
MEM_USAGE=$(free | grep Mem | awk '{printf("%.2f"), $3/$2 * 100.0}')

if (( $(echo "$MEM_USAGE > $THRESHOLD" | bc -l) )); then
    echo "⚠️  警告：内存使用率 ${MEM_USAGE}% 超过阈值 ${THRESHOLD}%"
fi
```

**磁盘监控：**
```bash
#!/bin/bash
# monitor_disk.sh

THRESHOLD=80
DISK_USAGE=$(df -h / | tail -1 | awk '{print $5}' | sed 's/%//')

if [ "$DISK_USAGE" -gt "$THRESHOLD" ]; then
    echo "⚠️  警告：磁盘使用率 ${DISK_USAGE}% 超过阈值 ${THRESHOLD}%"
fi
```

### 3.3 日志轮转

**配置 logrotate：**

```bash
# /etc/logrotate.d/openclaw-wecom

/opt/openclaw-wecom-project/logs/wecom/*.log {
    daily                    # 每天轮转
    rotate 30                # 保留30天
    compress                 # 压缩旧日志
    delaycompress            # 延迟压缩（第二次轮转时压缩）
    missingok                # 文件不存在不报错
    notifempty               # 空文件不轮转
    create 0644 root root    # 创建新文件权限
    sharedscripts
    postrotate
        docker compose restart wecom-gateway > /dev/null 2>&1
    endscript
}
```

**手动轮转：**
```bash
sudo logrotate -f /etc/logrotate.d/openclaw-wecom
```

## 五、备份恢复

### 5.1 备份策略

**推荐备份策略：**

| 备份类型 | 频率 | 保留时间 | 存储位置 |
|---------|------|---------|---------|
| 全量备份 | 每天 | 30天 | 本地 + 云存储 |
| 增量备份 | 每小时 | 7天 | 本地 |
| 配置备份 | 变更时 | 永久 | Git + 云存储 |

---

### 5.2 完整备份脚本

```bash
#!/bin/bash
# full_backup.sh

BACKUP_DIR="backups/$(date +%Y%m%d)"
mkdir -p "$BACKUP_DIR"

echo "开始完整备份..."

# 1. 备份数据库
echo "备份数据库..."
cp data/user_roles.db "$BACKUP_DIR/"

# 2. 备份配置文件
echo "备份配置..."
cp .env "$BACKUP_DIR/"
cp -r config/ "$BACKUP_DIR/"

# 3. 备份日志（最近7天）
echo "备份日志..."
mkdir -p "$BACKUP_DIR/logs"
find logs/ -name "*.log" -mtime -7 -exec cp {} "$BACKUP_DIR/logs/" \;

# 4. 压缩
echo "压缩备份..."
tar -czf "$BACKUP_DIR.tar.gz" "$BACKUP_DIR"
rm -rf "$BACKUP_DIR"

echo "✅ 备份完成: $BACKUP_DIR.tar.gz"

# 5. 上传到云存储（可选）
# aws s3 cp "$BACKUP_DIR.tar.gz" s3://my-backup-bucket/
# rclone copy "$BACKUP_DIR.tar.gz" remote:backup/
```

### 5.3 灾难恢复

**完整恢复流程：**

```bash
#!/bin/bash
# disaster_recovery.sh

BACKUP_FILE="$1"

if [ -z "$BACKUP_FILE" ]; then
    echo "用法: $0 <备份文件>"
    exit 1
fi

echo "开始灾难恢复..."

# 1. 停止服务
echo "停止服务..."
docker compose down

# 2. 解压备份
echo "解压备份..."
tar -xzf "$BACKUP_FILE"
BACKUP_DIR="${BACKUP_FILE%.tar.gz}"

# 3. 恢复数据库
echo "恢复数据库..."
cp "$BACKUP_DIR/user_roles.db" data/

# 4. 恢复配置
echo "恢复配置..."
cp "$BACKUP_DIR/.env" .
cp -r "$BACKUP_DIR/config/"* config/

# 5. 启动服务
echo "启动服务..."
docker compose up -d

# 6. 验证
echo "验证服务..."
sleep 5
curl -s http://localhost:8080/health

echo "✅ 恢复完成"
```

## 七、安全管理

### 7.1 访问控制

**配置防火墙：**

```bash
# Ubuntu (ufw)
sudo ufw allow 8080/tcp
sudo ufw allow from 192.168.1.0/24 to any port 8080

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" port port="8080" protocol="tcp" accept'
sudo firewall-cmd --reload
```
