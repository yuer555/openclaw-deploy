# OpenClaw 企业微信虚拟员工 - 快速部署指南

## 🚀 5分钟快速部署

**目标：** 从零到服务运行，最短时间内完成部署。

**前提条件：**
- Ubuntu 20.04+ / CentOS 8+ 服务器
- 外网 IP 地址
- Root 权限

---

## 方式一：一键部署脚本（推荐）

### 第一步：上传部署包

```bash
# 下载部署包（假设已有）
scp openclaw-wecom-project.tar.gz root@YOUR_SERVER:/opt/

# SSH 登录服务器
ssh root@YOUR_SERVER

# 解压
cd /opt
tar -xzf openclaw-wecom-project.tar.gz
cd openclaw-wecom-project
```

---

### 第二步：运行一键部署

```bash
# 赋予执行权限
chmod +x scripts/deploy.sh

# 运行部署脚本
./scripts/deploy.sh
```

**脚本会自动完成：**
- ✅ 检测操作系统
- ✅ 安装 Docker 和 Docker Compose
- ✅ 创建目录结构
- ✅ 初始化数据库
- ✅ 构建 Docker 镜像
- ✅ 启动服务
- ✅ 健康检查

**预计时间：** 5-10 分钟（取决于网络速度）

---

### 第三步：配置环境变量

```bash
# 编辑配置文件
vim .env
```

**填写企业微信参数：**
```env
WECOM_CORP_ID=ww1234567890abcdef
WECOM_SECRET=your_secret_here
WECOM_TOKEN=your_token_here
WECOM_ENCODING_AES_KEY=your_aes_key_43_chars
WECOM_AGENT_ID=1000002
```

**保存并退出：** ESC → `:wq` → 回车

---

### 第四步：重启服务

```bash
docker compose -f docker-compose-minimal.yml restart
```

---

### 第五步：验证服务

```bash
# 健康检查
curl http://localhost:8080/health

# 预期输出
{"status":"healthy","timestamp":1770792000}
```

## 方式二：手动部署

### 1. 安装 Docker

**Ubuntu/Debian:**
```bash
# 更新包索引
sudo apt update

# 安装依赖
sudo apt install -y apt-transport-https ca-certificates curl software-properties-common

# 添加 Docker 官方 GPG 密钥
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -

# 添加 Docker 仓库
sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"

# 安装 Docker
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker
```

**CentOS/RHEL:**
```bash
# 安装依赖
sudo yum install -y yum-utils

# 添加 Docker 仓库
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 安装 Docker
sudo yum install -y docker-ce docker-ce-cli containerd.io

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker
```

---

### 2. 安装 Docker Compose

```bash
# 下载 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# 赋予执行权限
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker-compose --version
```

---

### 3. 创建项目目录

```bash
mkdir -p /opt/openclaw-wecom-project/{data,logs/wecom,logs/nginx,config}
cd /opt/openclaw-wecom-project
```

---

### 4. 初始化数据库

```bash
sqlite3 data/user_roles.db << 'SQL'
CREATE TABLE IF NOT EXISTS user_roles (
    user_id TEXT PRIMARY KEY,
    roles TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS task_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id TEXT UNIQUE,
    user_id TEXT,
    agent_id TEXT,
    task_content TEXT,
    status TEXT,
    result TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS audit_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    event_type TEXT,
    user_id TEXT,
    details TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
SQL
```

---

### 5. 创建配置文件

**创建 .env：**
```bash
cat > .env << 'EOF'
WECOM_CORP_ID=ww_test_corp_id
WECOM_SECRET=test_secret
WECOM_TOKEN=test_token
WECOM_ENCODING_AES_KEY=test_aes_key_43_characters_long_padding_xxxx
WECOM_AGENT_ID=1000001
DB_PATH=/data/user_roles.db
LOG_LEVEL=INFO
EOF
```

---

### 6. 创建 docker-compose.yml

**复制项目中的配置文件，或手动创建。**

---

### 7. 启动服务

```bash
docker compose up -d --build
```

## 常见问题

### Q1: Docker 安装失败

**错误：** `Cannot connect to the Docker daemon`

**解决：**
```bash
sudo systemctl start docker
sudo systemctl enable docker
```

---

### Q2: 端口被占用

**错误：** `bind: address already in use`

**解决：**
```bash
# 查找占用端口的进程
netstat -tulpn | grep 8080

# 杀掉进程
sudo kill -9 PID

# 或修改端口
vim docker-compose-minimal.yml
# 修改 ports: "8081:80"
```

---

### Q3: 镜像构建缓慢

**原因：** 网络速度慢

**解决：**
```bash
# 配置 Docker 镜像加速
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.mirrors.ustc.edu.cn"
  ]
}
EOF

sudo systemctl restart docker
```

---

### Q4: 数据库初始化失败

**错误：** `database is locked`

**解决：**
```bash
# 停止服务
docker compose down

# 删除数据库
rm data/user_roles.db

# 重新初始化
./scripts/init_database.sh

# 启动服务
docker compose up -d
```
