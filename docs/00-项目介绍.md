# 📖 OpenClaw V1.4 - 项目介绍

> 企业微信智能虚拟员工系统 - 让 AI 成为你的得力助手

## 🎯 项目概述

**OpenClaw** 是一个基于 AI 的企业微信虚拟员工系统，通过多个智能代理（Agent）为企业提供自动化服务。系统支持任务分发、数据分析、技术支持等多种场景，显著提升团队协作效率。

### 核心特性
- 🤖 **多角色虚拟员工** - 5 种专业角色（运营、产品、开发、测试、客服），各司其职
- 🔗 **独立部署模式** - 每个 Agent 独立配置，按需启用
- 💬 **企业微信集成** - 无缝对接企业微信，每个 Agent 对应一个企业微信应用
- 🚀 **容器化部署** - Docker 一键部署，运维简单
- 🔒 **安全可靠** - 多层安全防护，数据隔离
- 📊 **实时监控** - 健康检查，日志完整

## 🔄 工作流程

### 1. 用户发起请求
```
用户在企业微信「运营助手」应用中 → 发送消息 → "帮我分析一下本月销售数据"
```

### 2. 企业微信回调
```
企业微信服务器 → 回调到 http://your-domain:8000/operation/wecom/callback
```

### 3. Gateway 路由
```
Gateway 接收消息 → 解析路径 /operation → 确定目标：运营专员 Agent (localhost:18791)
```

### 4. Agent 处理
```
Gateway 转发到运营专员容器 → OpenClaw 调用 AI 模型 → 分析数据 → 生成报告
```

### 5. 返回回复
```
运营专员 → 返回分析结果 → Gateway 接收 → 调用企业微信 API → 发送消息给用户
```

### 6. 用户接收
```
企业微信服务器 → 推送到用户 → 用户查看报告
```

**核心变化**：
- 用户通过不同的企业微信应用直接访问对应的 Agent
- Gateway 根据 URL 路径（`/{agent_name}/wecom/callback`）直接路由，无需 AI 意图识别
- 每个 Agent 独立配置企业微信 Token/Key

## 🔒 安全机制

### 1. 网络安全
- ✅ **SSL/TLS 加密** - HTTPS 传输，防止中间人攻击
- ✅ **防火墙规则** - 只开放必要端口（80, 443）
- ✅ **网络隔离** - Docker 网络隔离，容器间独立通信

### 2. 数据安全
- ✅ **API Key 加密存储** - Docker Secrets 管理敏感信息
- ✅ **数据库加密** - 敏感数据加密存储
- ✅ **日志脱敏** - 自动过滤敏感信息

### 3. 访问控制
- ✅ **企业微信认证** - 只有企业成员可访问
- ✅ **权限分级** - 不同角色不同权限
- ✅ **会话管理** - 超时自动登出

### 4. 审计与监控
- ✅ **操作日志** - 完整记录所有操作
- ✅ **异常告警** - 实时监控异常行为
- ✅ **健康检查** - 自动检测服务状态

## 📊 技术栈

### 后端
- **运行时**: Node.js 25+
- **框架**: OpenClaw Framework
- **AI 模型**: GitHub Copilot / OpenAI GPT-4
- **数据库**: SQLite（默认）/ PostgreSQL（可选）

### 容器化
- **容器引擎**: Docker
- **编排工具**: Docker Compose
- **镜像仓库**: Docker Hub

### 反向代理
- **Web 服务器**: Nginx
- **SSL 证书**: Let's Encrypt
- **负载均衡**: Nginx Upstream

### 监控与日志
- **日志管理**: Docker Logging Driver
- **健康检查**: Docker Healthcheck
- **监控工具**: Prometheus + Grafana（可选）
