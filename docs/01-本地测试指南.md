# 本地测试指南

> 多 Agent 独立配置架构 - 本地部署教程

## 架构概览

```
本地宿主机
├── Gateway (Flask, :8000) - 宿主机运行
│   ├── /operation/wecom/callback    → 运营专员 (:18791)
│   ├── /product/wecom/callback      → 产品经理 (:18792)
│   ├── /development/wecom/callback  → 开发工程师 (:18793)
│   ├── /testing/wecom/callback      → 测试工程师 (:18794)
│   └── /service/wecom/callback      → 客服专员 (:18795)
│
├── openclaw-agent-operation  (Docker 容器, localhost:18791)
├── openclaw-agent-product    (Docker 容器, localhost:18792)
├── openclaw-agent-development(Docker 容器, localhost:18793)
├── openclaw-agent-testing    (Docker 容器, localhost:18794)
└── openclaw-agent-service    (Docker 容器, localhost:18795)
```

**架构说明**：
- Gateway 在宿主机运行（不使用容器），通过 URL 路径路由到不同 Agent
- 每个 Agent 是独立的 Docker 容器，可通过 `.env.local` 按需启用/禁用
- 容器通过 `openclaw-network` Docker 网络互联
- 取消了 Dispatcher 调度员，每个 Agent 对应一个企业微信应用

---

## 前置条件

- Docker Desktop（macOS/Linux/WSL2）
- 至少 8GB 内存，10GB 磁盘
- Python 3.13+（宿主机运行 Gateway）
- GitHub Token 或 OpenAI API Key

## 快速开始

### 第一步：初始化环境

```bash
cd local/
./1-init-local.sh
```

检查端口占用（8000、18791-18795），创建数据目录，生成 `.env.local`。

### 第二步：配置环境变量

```bash
vi .env.local
```

**必填项（AI 模型配置）**：

```bash
# OpenAI 兼容 API
API_KEY=your_api_key_here
API_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4

# 或使用 GitHub Copilot
# API_BASE_URL=https://api.githubcopilot.com
# MODEL_PROVIDER=anthropic
# MODEL_API=openai-responses
```

**Agent 启用配置（至少启用一个）**：

```bash
# 启用运营专员
AGENT_OPERATION_ENABLE=true
AGENT_OPERATION_WECOM_TOKEN=your_operation_token
AGENT_OPERATION_WECOM_ENCODING_AES_KEY=your_operation_key
AGENT_OPERATION_PORT=18791

# 启用开发工程师
AGENT_DEVELOPMENT_ENABLE=true
AGENT_DEVELOPMENT_WECOM_TOKEN=your_development_token
AGENT_DEVELOPMENT_WECOM_ENCODING_AES_KEY=your_development_key
AGENT_DEVELOPMENT_PORT=18793

# 其他 Agent 类似配置...
```

**注意**：
- 每个 Agent 需要独立的企业微信 Token 和 EncodingAESKey（对应不同的企业微信应用）
- 只有 `AGENT_{ROLE}_ENABLE=true` 的 Agent 会被启动

### 第三步：构建镜像

```bash
./0-build-images.sh
```

构建 base 镜像和 5 个 `openclaw-agent-{role}:local` 镜像。首次构建需要下载依赖，耗时较长（5-10 分钟）。

### 第四步：启动服务

```bash
./2-start-local.sh
```

- 启动 enabled 的 Agent 容器
- 在宿主机启动 Gateway (Flask)
- 等待健康检查通过

### 第五步：验证服务

```bash
./3-test-local.sh
```

测试所有 enabled 的 Agent 健康检查和路由功能。

## 常用操作

```bash
# 查看 Gateway 日志
tail -f /tmp/openclaw/flask.log

# 查看某个 Agent 日志
docker logs openclaw-agent-development -f

# 停止所有服务
./4-stop-local.sh

# 清理所有容器、镜像和数据
./5-clean-local.sh

# 代码变更后重新构建
./0-build-images.sh && ./2-start-local.sh

pkill -f wecom_gateway.py
../scripts/start-gateway.sh
```

## 常见问题

**Q: 端口被占用？**

```bash
# 检查端口占用
lsof -i :8000
lsof -i :18793

# 杀掉占用进程
kill -9 <PID>
```

**Q: 镜像构建失败？**

检查网络连接，npm 镜像使用 npmmirror.com，如需更换：

```bash
# 在 config/Dockerfile.agents 中修改
RUN npm config set registry https://registry.npmjs.org
```

**Q: Agent 健康检查超时？**

OpenClaw 首次启动需要安装依赖，等待时间较长（1-3 分钟）。查看日志：

```bash
docker logs openclaw-agent-operation -f
```

等待出现 `Server running on port 18789` 日志。

**Q: Gateway 启动失败？**

检查 Python 依赖是否安装：

```bash
cd src/gateway
pip3 install -r requirements.txt
```

检查环境变量是否配置：

```bash
cat local/.env.local
```

**Q: 没有启用任何 Agent？**

至少需要启用一个 Agent，在 `.env.local` 中设置：

```bash
AGENT_DEVELOPMENT_ENABLE=true
```

**Q: 企业微信回调验证失败？**

检查 Token 和 EncodingAESKey 是否正确：

```bash
# 在企业微信管理后台查看配置
# 确保与 .env.local 中的 AGENT_{ROLE}_WECOM_* 一致
```

## 数据目录

```
data/
├── gateway/          # Gateway 数据库（SQLite）和日志
│   └── gateway.db    # 消息队列、会话数据
└── agents/           # Agent 工作空间（当前不使用，角色文件在镜像内）
    ├── operation/
    ├── product/
    ├── development/
    ├── testing/
    └── service/

shared-files/         # Agent 共享文件目录（只读挂载到容器）
```

**说明**：
- Agent 的角色定义文件（IDENTITY.md, SOUL.md, AGENTS.md, TOOLS.md, USER.md）在镜像内预置
- `data/agents/{role}/` 目录当前未使用，未来可用于持久化对话历史
- `shared-files/` 用于 Agent 之间共享文件（如文档、图片等）

## 测试示例

### 1. 测试路由功能

```bash
# 发送测试消息到开发工程师
curl -X POST http://localhost:8000/test/send \
  -H "Content-Type: application/json" \
  -d '{
    "agent_name": "development",
    "user_id": "test-user",
    "content": "帮我写个测试用例"
  }'
```

### 2. 手动测试企业微信回调

```bash
# 模拟企业微信 GET 验证（需要真实的签名参数）
curl "http://localhost:8000/development/wecom/callback?msg_signature=xxx&timestamp=xxx&nonce=xxx&echostr=xxx"
```

### 3. 查看 Agent 版本信息

```bash
docker exec openclaw-agent-development openclaw --version
```
