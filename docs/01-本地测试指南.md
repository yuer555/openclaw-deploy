# 本地测试指南

> 三层 Docker 架构本地部署教程

## 架构概览

```
本地宿主机
├── openclaw-gateway (localhost:8000)
│   ├── Flask 网关（企业微信 + Telegram）
│   └── openclaw 调度员（:18789，内部）
├── openclaw-agent-operation  (localhost:18791)
├── openclaw-agent-product    (localhost:18792)
├── openclaw-agent-development(localhost:18793)
├── openclaw-agent-testing    (localhost:18794)
└── openclaw-agent-service    (localhost:18795)
```

所有容器通过 `openclaw-network` Docker 网络互联。

---

## 前置条件

- Docker Desktop（macOS/Linux/WSL2）
- 至少 8GB 内存，10GB 磁盘
- GitHub Token 或 OpenAI API Key

---

## 快速开始

### 第一步：初始化环境

```bash
cd local/
./1-init-local.sh
```

检查端口占用（8000、18791-18795），创建数据目录，生成 `.env.local`。

### 第二步：配置环境变量

```bash
vi .env.local
```

必填项：

```bash
GITHUB_TOKEN=your_github_token_here
```

可选（企业微信）：

```bash
WECOM_CORP_ID=your_corp_id
WECOM_SECRET=your_secret
WECOM_TOKEN=your_token
WECOM_ENCODING_AES_KEY=your_key
WECOM_AGENT_ID=your_agent_id
```

可选（Telegram）：

```bash
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_MODE=polling
```

### 第三步：构建镜像

```bash
./0-build-images.sh
```

构建 `openclaw-gateway:local` 和 5 个 `openclaw-agent-{role}:local` 镜像。首次构建需要下载依赖，耗时较长。

### 第四步：启动服务

```bash
./2-start-local.sh
```

依次启动 agent 容器和 gateway 容器，等待健康检查通过。

### 第五步：验证服务

```bash
./3-test-local.sh
```

测试所有容器健康检查和消息路由。

## 常用操作

```bash
# 查看 gateway 日志
docker logs openclaw-gateway -f

# 查看某个 agent 日志
docker logs openclaw-agent-testing -f

# 停止所有服务
./4-stop-local.sh

# 清理所有容器、镜像和数据
./5-clean-local.sh

# 代码变更后重新构建
./0-build-images.sh && ./2-start-local.sh
```

## 常见问题

**端口被占用**

```bash
lsof -i :8000
kill -9 <PID>
```

**镜像构建失败**

检查网络连接，npm 镜像使用 npmmirror.com，如需更换：

```bash
# 在 Dockerfile.agents 中修改
RUN npm config set registry https://registry.npmjs.org
```

**Agent 健康检查超时**

openclaw 首次启动需要安装依赖，等待时间较长（1-3 分钟）。查看日志：

```bash
docker logs openclaw-agent-operation -f
```

**AI 路由不工作**

确认 `GITHUB_TOKEN` 或 `OPENAI_API_KEY` 已正确配置，调度员 openclaw 需要 AI 模型支持。
