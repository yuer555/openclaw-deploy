# 🏠 本地测试指南

> 零基础入门：在你的电脑上测试 OpenClaw 虚拟员工系统

## 📖 简介

本指南将手把手教你在本地电脑上运行 OpenClaw，无需云服务器，无需域名，5分钟即可开始测试！

## 🎯 适用人群

- ✅ 第一次接触 OpenClaw 的新手
- ✅ 想在部署前先测试功能
- ✅ 开发者进行本地开发
- ✅ 不想花钱租服务器先试试

## ✅ 准备工作

### 系统要求
- **操作系统**: macOS 或 Linux（Windows 用户可用 WSL2）
- **内存**: 至少 8GB
- **磁盘空间**: 至少 5GB
- **网络**: 需要访问互联网（下载镜像、调用 API）

### 必须安装的软件

#### 1️⃣ Docker Desktop
Docker 是运行 OpenClaw 的容器平台。

**macOS 安装：**
```bash
# 方法1: 官网下载（推荐）
# 访问 https://www.docker.com/products/docker-desktop
# 下载并安装 Docker Desktop for Mac

# 方法2: 使用 Homebrew
brew install --cask docker
```

**Linux 安装：**
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo systemctl start docker
sudo systemctl enable docker
```

**验证安装：**
```bash
docker --version
# 应输出: Docker version 24.x.x

docker compose version
# 应输出: Docker Compose version v2.x.x
```

#### 2️⃣ 准备 AI API Key

OpenClaw 需要 AI 模型支持，你有两个选择：

**选项 1: GitHub Copilot（推荐，免费）**
1. 访问 https://github.com/settings/tokens
2. 点击 "Generate new token (classic)"
3. 勾选 `copilot` 权限
4. 点击 "Generate token"
5. **保存好这个 Token**（后面会用到）

**选项 2: OpenAI API**
1. 访问 https://platform.openai.com/api-keys
2. 点击 "Create new secret key"
3. **保存好这个 API Key**（后面会用到）

### 第一步：进入本地测试目录

```bash
cd /Users/marty/openclaw-deploy/local
```

### 第二步：初始化环境

运行初始化脚本：
```bash

```

这个脚本会：
- ✅ 检查 Docker 是否安装
- ✅ 创建必要的目录
- ✅ 生成配置文件模板

**预期输出：**
```

✅ .env.local 创建成功
⚠️  重要：请编辑 .env.local 文件，填入你的 API Key！
```

### 第三步：配置 API Key

编辑配置文件：
```bash
vi .env.local
# 或使用你喜欢的编辑器
# nano .env.local
# code .env.local
```

**找到这一行：**
```bash
GITHUB_TOKEN=your_github_token_here
```

**替换为你的真实 Token：**
```bash
GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**保存并退出**

> 💡 提示：如果使用 OpenAI，则修改 `OPENAI_API_KEY=sk-xxxxxx`

```bash

```

这个脚本会：
- ⏬ 拉取 Docker 镜像（首次运行需要几分钟）
- 🚀 启动 OpenClaw 容器

## ❓ 常见问题

### Q1: Docker 启动失败

**问题：**
```
Cannot connect to the Docker daemon
```

**解决：**
1. 确保 Docker Desktop 正在运行
2. macOS: 在菜单栏检查 Docker 图标
3. Linux: 运行 `sudo systemctl start docker`

### Q2: 端口被占用

**问题：**
```
Bind for 0.0.0.0:3000 failed: port is already allocated
```

**解决：**
1. 查找占用端口的进程：
   ```bash
   lsof -i :3000
   ```
2. 停止该进程或修改 `.env.local` 中的端口号

### Q3: 容器启动后立即退出

**问题：**
```
container openclaw-local is unhealthy
```

**解决：**
1. 查看详细日志：
   ```bash
   docker logs openclaw-local --tail=100
   ```
2. 常见原因：
   - API Key 配置错误
   - 配置文件格式错误
   - 依赖服务未启动

### Q4: 镜像下载很慢

**解决：**
配置 Docker 镜像加速（中国大陆用户）：
```bash
# 编辑 Docker 配置
sudo vi /etc/docker/daemon.json

# 添加以下内容：
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com"
  ]
}

# 重启 Docker
sudo systemctl restart docker
```
